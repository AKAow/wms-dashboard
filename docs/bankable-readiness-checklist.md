# WMS Bankable Readiness Checklist (v0)

## 1) 데이터/추적성
- [ ] 원본 관측 데이터 보관 (수정 금지)
- [ ] QA/QC 처리 이력 저장 (결측/이상치/보간)
- [ ] 모델 실행 버전, 실행자, 실행시각 저장
- [ ] 보고서 생성 시점의 입력 스냅샷 저장

## 2) 모델/가정 관리
- [ ] 표준 터빈 시나리오 3종 운영 (S/M/L)
- [ ] 프로젝트별 후보 기종 파워커브 교체 가능 구조
- [ ] 손실 항목 분리 (availability/electrical/wake/curtailment/icing/other)
- [ ] 가정값 버전관리 및 변경로그

## 3) 검증/신뢰도
- [ ] 30/90/365일 백테스트 자동화
- [ ] MAPE/NMAE/Bias 계산
- [ ] A/B/C 신뢰도 등급 표시
- [ ] 기존 단순식 대비 성능 비교표

## 4) 불확실성/P-값
- [ ] P50/P75/P90 산정 근거 문서화
- [ ] 고정 배율 대신 오차분포 기반 산정
- [ ] 데이터 커버리지/품질지수 반영

## 5) 보고서/증적
- [ ] 제출용 PDF 템플릿 (가정/결과/리스크/민감도)
- [ ] 보증 아님 문구 + 책임범위 명시
- [ ] 보고서 메타데이터(모델/버전/생성시각/입력범위) 포함
- [ ] 제3자 검토 코멘트 첨부 가능 구조

---

## 구현 순서 (권장)
1. 표준 시나리오 + 손실 구조 + 계산엔진 분리
2. 백테스트/신뢰도 API + UI 카드
3. P50/P75/P90 고도화(오차분포 기반)
4. PDF 자동 보고서 + 메타데이터 고정
5. 외부 검토 프로세스 연결
